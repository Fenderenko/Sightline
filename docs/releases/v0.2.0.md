Перший публічний реліз Sightline — власний приціл поверх ігор (borderless / windowed fullscreen) без ін'єкцій у гру.

### Встановлення
Розпакуйте `Sightline-v0.2.0-win-x64.zip` і запустіть `sightline.exe`. Налаштування — через іконку в треї або Ctrl+Shift+F11.
Exe не підписані, тому SmartScreen може попередити: «Докладніше» → «Виконати в будь-якому разі».

### Що всередині
- 59 пресетів (найпопулярніші зверху), пошук, категорії, обрані
- Конструктор: 13 форм, шари, обводка, палітра кольору, undo/redo, коліщатко на повзунках, явне збереження (пресети не змінюються)
- Піксельно симетричні приціли
- Імпорт кодів Sightline / Valorant / CS2, експорт та імпорт бібліотеки
- Профілі ігор, ADS (сховати / показати / інший приціл), приховування на робочому столі, при курсорі, лише в повноекранних іграх
- Світла й темна теми, українська та англійська
- Ядро: ~2,5 MB RAM, 0% CPU у простої, жодних хуків, драйверів чи читання пам'яті

Збірка виконана GitHub Actions з цього тегу.
