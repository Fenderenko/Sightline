Show the crosshair only in your games.

### Install
Unzip `Sightline-v0.3.1-win-x64.zip` and run `sightline.exe`. From v0.3.0 you can also update in place: Settings → About → Check for updates.
The executables are not code-signed, so SmartScreen may warn on the first run from a downloaded zip: "More info" → "Run anyway". To avoid it, right-click the zip → Properties → tick "Unblock" → OK, then unzip.

### Changes
- Game profiles → "Where the crosshair shows" → **Only my games**: the crosshair appears only in the games from your profiles (plus an optional extra list). Browsers and other apps get no crosshair.
- A warning appears when this mode is on but no game has been added yet.
- Texts updated in all nine languages.
