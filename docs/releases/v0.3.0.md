A redesigned editor, crosshair blur, nine interface languages and updates from inside the app.

### Install
Unzip `Sightline-v0.3.0-win-x64.zip` and run `sightline.exe`. Settings open from the tray icon or Ctrl+Shift+F11.
The executables are not code-signed, so SmartScreen may warn: "More info" → "Run anyway".
Coming from v0.2.0: unzip over the old folder. Your config and crosshairs stay in `%APPDATA%\Sightline`.

### Editor
- Fill and outline groups share the same rows (colour · opacity · blur), lined up in one column.
- Compact value fields: drag sideways, click to type, or use the mouse wheel.
- Fill and outline blur, for a soft crosshair or a soft shadow / glow.
- Colour is set with the picker or a hex value; the fixed swatch rows are gone.
- Canvas rulers with pixel offsets from the centre, and centre axes.
- Copy / paste a layer or just its style (Ctrl+C / Ctrl+V / Ctrl+Shift+V). Each layer shows its shape icon.
- Sizes cannot drop to zero, so a crosshair never vanishes. The last ray cannot be switched off.

### App
- Custom title bar: the name appears once, in the sidebar.
- Game profiles: pick the game's exe with Browse… or from a searchable list of running apps with icons.
- The core status shows only when the core is not running, with a Start button.
- Settings → About: version, update check and in-place install, links to GitHub and the author. Nothing is checked on its own.
- Settings → Files: open the settings and logs folders.
- Languages: English (default), Ukrainian, German, French, Spanish, Portuguese (Brazil), Polish, Italian, Turkish.
- Dark theme by default.

### Fixes
- A wheel notch that scrolled the inspector no longer also changes the slider that ends up under the pointer.
